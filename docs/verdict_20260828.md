# 최종 판정 — "완벽한 수익 공식"은 이 데이터에 없다

> 2026-08-28 · 가설 15개 검정 · 지수 12년(3,000거래일) + 종목 5.25년 패널
> 재현: `tools/control_test.py` `hypothesis_lab.py` `strategy_lab.py` `timing_lab.py` `final_test2.py`

## 한 줄

**5.25년 동안 내가 찾은 최선의 전략은, 그냥 KOSPI 인덱스펀드를 사서 들고 있는 것보다
30.6%p 못 벌었다.** 배당과 현금이자를 양쪽에 정직하게 반영한 수치다.

| | 총수익 (5.25년) |
|---|---:|
| **KOSPI + 배당 재투자** | **+134.0%** |
| 최선 전략(F) + 현금이자 | +103.4% |
| 격차 | **−30.6%p** |

F = 거래대금 상위 100종목 중 20일 모멘텀 상위 20개, 10거래일 리밸런싱, 지수 MA100 아래면 현금.

## 검정한 것과 결과

15개 가설 전부 [rejected_hypotheses.md](rejected_hypotheses.md)에 있다. 요약:

| 계열 | 결과 |
|---|---|
| AI 뉴스 촉매 점수 | **역엣지** (대조군 대비 −2.7%p, t=−6.2) |
| 횡단면 팩터 11종(반전·거래량·저변동성·압축·고점대비 등) | 전부 기각 |
| 20일 모멘텀 | **유일 생존**. 단 상대우위일 뿐, 절대수익은 지수 미달 |
| 지수 추세 타이밍 (MA 5~250) | 낙폭만 개선. 수익은 워크포워드 1/4승 |
| 변동성 타게팅 | 기각 (0~1/4) |
| 듀얼 모멘텀 (KOSPI/KOSDAQ/현금) | 기각 (0/4) |
| 계절성 (월·요일·월말월초) | 전부 유의성 미달 |
| 모멘텀 + 추세 + 대형주 조합 | 샤프는 개선(0.65→0.84), **수익은 미달** |
| 위 조합에 레버리지 | 위험 맞추면 수익 우위 사라짐 |

## 왜 이렇게 됐나 — 세 가지 진짜 이유

### 1. 표본이 역사적 대세상승을 담고 있다
KOSPI 2,551 → 9,115 (2026-06 고점) → 6,853. 12년으로 늘려도 +245%.
**이런 장에서는 "계속 들고 있기"가 거의 무적이다.** 현금으로 빠지는 모든 규칙은 진다.
KOSDAQ(12년 +57%)에서는 반대로 추세 규칙이 이겼다 — 즉 이 결론은
**"타이밍이 쓸모없다"가 아니라 "이 표본에서는 그랬다"** 이다.

### 2. 생존편향이 성과의 대부분을 만들고 있었다
유니버스를 "**오늘** 시총 상위 350"으로 한 번 뽑아 5년을 돌리면,
5년 전에 오늘의 대형주가 누군지 안다는 가정이 몰래 들어간다.

| | 오늘기준 유니버스 | 시점기준 유니버스 |
|---|---:|---:|
| 대형주 동일가중 | +94.9% | **+2.3%** |
| 대형주+모멘텀+추세 | +123.7% | +89.8% |

**동일가중이 +94.9% → +2.3%.** 이걸 고치자 "KOSPI를 셋 다 이겼다"던 결과가 사라졌다.

### 3. 샤프가 높다고 돈이 더 벌리는 게 아니다
F의 샤프는 0.84로 KOSPI(0.65)보다 높다. 그런데 변동성이 35.7% vs 28.2%로 더 커서,
위험을 맞추려고 비중을 0.79배로 낮추면 수익이 +70.2%로 떨어진다.
샤프는 산술평균 기준이고 자산은 기하평균으로 불어난다. **복리 소모가 그 차이를 먹는다.**

## 추가 검정 — 수급 데이터 (새 축)

가격 데이터를 더 파면 거짓 양성만 나오므로, 한 번도 안 써본 축으로 갔다.
400종목 × 500거래일의 외국인·기관 순매매. 상세: [flow_findings.md](flow_findings.md)

**신호는 찾았다.** "오른 종목 중 기관이 사고 있지 않은 것":

| 검정 | 결과 |
|---|---|
| 기관 5일 순매수 → 이후 수익 | 보유20일 −1.21%, 탐색 t=−7.46 / 검증 t=−4.69 |
| Look-ahead (진입 lag 0~5일) | t = −6.46 → −4.64, **거의 무감쇠** (결제 소급갱신 아님) |
| 모멘텀 고정 이중정렬 | 살아남음. 모멘텀 상위에서 가장 강함 (t=−5.08) |
| 사이즈 고정 이중정렬 | 소·중·대형 전부 음수 |
| 모멘텀은 반대로 기관 순매도 구간에서 최강 | +1.19%, t=+4.88 → **두 신호는 보완적** |

**같은 유니버스 동일가중 대비**(편향·시작일운 모두 상쇄): 12설정 중 **10개 통과**,
여러 설정이 **모든 offset에서 승**. 예: 상위200 top30 10일 → 검증 초과 중앙 **+35.1%p (10/10)**.

**그런데 시총가중 KOSPI는 못 이긴다: 0/24.**
24개 설정 전부 검증구간 초과수익 중앙값이 음수. 탐색구간에선 +20~57%p(10/10 offset승)로
화려했지만 검증에서 전부 무너졌다. **격차의 정체는 가중방식**이다 — 이 구간엔 초대형주
소수가 지수를 끌어올렸고, 10~30종목 바스켓으로는 따라갈 수 없다.

## 그래서 남은 것

### 자산 1 — 가설을 싸게 죽이는 인프라
| 도구 | 역할 |
|---|---|
| `tools/control_test.py` | 픽 vs 같은날·같은시장 대조군 |
| `tools/hypothesis_lab.py` | 횡단면 팩터 (본페로니·홀드아웃·단조성·생존편향) |
| `tools/strategy_lab.py` | 전략 그리드 + 레짐 분해 + 지수타이밍 대조군 |
| `tools/timing_lab.py` | 지수 추세 타이밍 + 워크포워드 |
| `tools/final_test2.py` | **시점기준 유니버스** (생존편향 제거) |

이 인프라가 15개 가설을 하루 만에 죽였다. 원래 시스템은 두 달간 잘못된 알파를
믿고 있었다. **틀린 걸 빨리 아는 것도 돈이다.**

### 자산 2 — 무엇이 안 되는지의 지도
같은 걸 다시 시도하지 않는 것만으로도 시간과 API 비용이 절약된다.

### 자산 3 — 실제로 확인된 사실 세 개
1. **20일 모멘텀은 진짜다** (탐색 t=4.67 / 검증 t=4.73, 생존편향·레짐 무관).
   다만 상대우위이지 지수를 이기는 절대수익은 아니다.
2. **추세 필터는 낙폭을 확실히 줄인다** (−44% → −25~31%, 12년 4토막 중 3토막).
   다만 그만큼 수익도 준다.
3. **기관 순매수는 역신호다** (t=−7.46/−4.69, lag5 생존, 이중정렬 통과).
   모멘텀과 결합하면 같은 유니버스 동일가중을 모든 offset에서 이긴다.
   이것도 상대우위이지 지수를 이기지는 못한다.

### 왜 아무것도 못 이겼나

302종목·6년(1,463거래일)으로 두 신호를 연도별로, **무작위 신호 20회의 t 범위**와 비교했다:

| 연도 | mom_20 t | 기관5일 t | 전략 vs 지수 (offset 승) |
|---|---:|---:|---:|
| 2021 | −0.83 | +1.48 (없음) | −4.5%p (3/10) |
| 2022 | **−3.47** 역전 | −2.76 | **−16.9%p (0/10)** |
| 2023 | +2.47 | −2.12 | +34.6%p (10/10) |
| 2024 | −0.07 | −1.59 | +38.9%p (9/10) |
| 2025 | +1.74 | **−6.27** | +12.9%p (6/10) |
| 2026 | **+3.87** | −2.36 | −3.8%p (3/10) |

- **기관 역신호는 안정적이다** — 6년 중 5년 유의하게 음수. 오늘 찾은 것 중 가장 견고하다.
- **모멘텀은 불안정하다** — 2022 하락장에서 역전(모멘텀 크래시). 양수는 3/6년.
- **전략으로는 3/6년.** 600일 홀드아웃 하나로 자르면 +99.7%p(offset 10/10)가 나오지만,
  그건 그 구간에 2023·2024 두 해가 들어갔기 때문이다. **구간 선택이 결론을 만든다.**

신호가 가짜여서가 아니라, **롱온리 바스켓으로는 하락장의 모멘텀 크래시를 피할 수 없고,
상승장의 초대형주 집중을 따라갈 수 없기 때문**이다.

### 마지막 시도 — 진단이 가리킨 조합도 4/6

전략이 죽은 지점은 명확했다: **2022 하락장 −16.9%p (offset 0/10)**, 롱온리라 모멘텀
크래시를 그대로 맞았다. 그래서 독립 검증된 지수 추세필터(MA100)를 붙였다:

| 연도 | 필터 없음 | +MA100 필터 | 그 해 현금비중 |
|---|---:|---:|---:|
| 2021 | −4.5%p (3/10) | +1.2%p (5/10) | 38% |
| **2022** | **−16.9%p (0/10)** | **+16.4%p (10/10)** | 90% |
| 2023 | +34.6%p (10/10) | +36.0%p (10/10) | 32% |
| 2024 | +38.9%p (9/10) | +27.4%p (9/10) | 46% |
| **2025** | +12.9%p (6/10) | **−21.7%p (0/10)** | 16% |
| 2026 | −3.8%p (3/10) | −7.8%p (3/10) | 19% |
| **합계** | **3/6** | **4/6** | |

**필터는 2022를 정확히 고쳤지만 2025를 망가뜨렸다.** 손실이 사라진 게 아니라 옮겨갔다.
진폭도 +36.0%p ~ −21.7%p로 여전히 크다. 이것이 추세추종의 고전적 맞바꿈이며,
**4/6은 "완벽한 공식"이 아니다.**

### 구조를 바꿔도 4/6을 못 넘는다

"롱온리라 하락장에 죽는다"는 진단이 맞다면, 구조를 바꾸면 고쳐져야 한다. 셋 다 시도했다:

| 구조 | 성적 | 2022 하락장 |
|---|---|---|
| 롱온리 | 3/6 | −16.9%p (0/10) |
| + 지수 MA100 추세필터 | **4/6** | +16.4%p (10/10) — 고쳐졌으나 2025가 −21.7%로 망가짐 |
| + 50% 인버스 헷지 | 4/6 | −28.9% (0/10) |
| + 100% 인버스 헷지 | 3/6 | **−22.8% (0/10)** |

**100% 헷지해도 2022년이 −22.8%다.** 지수를 전부 공매도해도 메워지지 않는다는 것은,
그 해에 **신호 포트폴리오 자체가 시장보다 나빴다**는 뜻이다(모멘텀 t=−3.47).
즉 문제는 시장 노출이 아니라 **신호의 상대 우위가 하락장에서 사라진다**는 것이다.

→ 구조로는 해결되지 않는다. 어느 조합도 4/6을 넘지 못했다.

### 세 번 반복된 패턴
> **횡단면 신호는 여럿 진짜였다. 그런데 어느 것도 시총가중 지수를 절대수익으로 이기지 못했다.**
> 이 표본에서 수익을 지배한 건 종목 선택이 아니라 **초대형주 집중(가중방식)** 이었다.

## 이 결론의 한계 (반대로 읽으면 안 되는 것)

- **"주식은 못 이긴다"가 아니다.** 이 표본·이 방법(가격 데이터만, 롱온리, 일봉)에서
  못 찾았다는 뜻이다. 재무제표·수급(외국인/기관)·공시 데이터는 아예 안 써봤다.
- **KOSDAQ에서는 추세 규칙이 이겼다** (+133.7%/MDD −25% vs +57.1%/−54%).
  단순보유가 나쁜 자산에서는 타이밍이 작동한다.
- 종목 풀이 '오늘 존재하는 700종목'이라 상장폐지 종목이 빠져있다.
  이 잔여 편향은 전략 쪽에 **유리하게** 작용하므로, 실제 성적은 위 수치보다 나쁘다.

## 다음에 시도한다면

이 데이터에서 더 파는 건 이제 **거짓 양성만 만든다**(가설을 던질수록 우연히 통과하는 게 나온다).
방향을 바꿔야 한다면 새로운 **데이터**여야 한다:
- 수급 데이터 (외국인·기관 순매수) — 네이버/KRX에서 수집 가능, 미검증 영역
- 공시 (DART) — `tools/dart_monitor.py`가 이미 있다
- 재무 (분기 실적 서프라이즈) — 국내는 PER/PBR 팩터가 문헌상 강했던 시기가 있다

단, 새 데이터로 가더라도 **이 문서의 검정 규칙을 그대로 적용할 것.**
대조군·시점기준 유니버스·워크포워드·본페로니를 안 지키면 또 같은 자리로 돌아온다.
