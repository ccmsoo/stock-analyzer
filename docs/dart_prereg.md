1. 전 구간 **|t| ≥ 2.87** (본페로니)
2. 검증구간(뒤 40%) **|t| ≥ 2.0**
3. 탐색·검증 **부호 일치**
4. 보유 3일과 10일에서 **부호 일치** (한 기간에만 나오면 우연)

하나라도 못 넘기면 **기각**이다. 결과가 아까워도 기준을 낮추지 않는다.

## 도중에 잡은 버그

`n<60` 필터가 자사주취득·자사주소각·전환사채를 부당하게 탈락시키고 있었다.
사전등록 명세("유형당 60건")에 맞게 이벤트 수로 고친 뒤 재실행했다 —
**기준을 낮춘 게 아니라 코드를 명세에 맞춘 것**이며, 고친 뒤에도 생존은 0개다.
